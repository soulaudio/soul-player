DEBUGGING GUIDE
===============

Q: "Is the 100ms fix compiled?"
A: Check logs for:
   [SEEK PERF] === Position Update EMIT === after 9823 samples (~100ms @ 48000Hz)

   If shows "~100ms" → ✓ Fix is compiled
   If shows "~500ms" → ✗ Need to rebuild

Q: "Where is time being spent?"
A: Compare timestamps:
   - Store update > 1ms → React slow
   - Invoke > 5ms → IPC overhead
   - Manager > 20ms → Decoder slow
   - Position update > 120ms → Throttle broken

Q: "Is ignore window working?"
A: Position updates should NOT appear between:
   - "Ignore window enabled" and "Ignore window DISABLED"

   If positions appear during this time → Ignore window not working

Q: "Is there lock contention?"
A: Check log for:
   [SEEK PERF] Lock acquired in 15.67ms

   If > 5ms → Audio thread is busy (unusual)

Q: "Is decoder the bottleneck?"
A: Check decoder timing:
   - FLAC < 5ms → OK
   - FLAC 10-50ms → Acceptable
   - FLAC > 50ms → Investigate
   - MP3 20-50ms → Expected (VBR)
   - MP3 > 100ms → Possible file issue


HOW TO READ LOGS
================

Good Seek (FLAC):
  Store: 0.4ms ✓
  Invoke: 3.2ms ✓
  Manager: 5.1ms ✓
  Decoder: 2.8ms ✓
  Total: 130ms ✓

Slow Decoder (MP3 VBR):
  Store: 0.3ms ✓
  Invoke: 3.1ms ✓
  Manager: 42.5ms ⚠ (expected for MP3)
  Decoder: 42.1ms ⚠ (normal for VBR)
  Total: 165ms (OK for MP3)

Lock Contention (unusual):
  Lock acquired in: 15.2ms ✗
  Indicates audio thread is busy
  Check for background processing

React Slow:
  Store update: 12.3ms ✗
  IPC/backend: 3.2ms ✓
  Indicates React performance issue


ENABLE LOGGING
==============

Development (macOS/Linux):
  RUST_LOG=soul_playback=info cargo xtask dev desktop

Development (Windows PowerShell):
  $env:RUST_LOG="soul_playback=info"
  cargo xtask dev desktop

Full Tracing (More Details):
  RUST_LOG=soul_playback=trace cargo xtask dev desktop

Production (Windows):
  [Environment]::SetEnvironmentVariable("RUST_LOG", "soul_playback=info", [EnvironmentVariableTarget]::User)
  # Then restart Soul Player
  # Logs: %APPDATA%\Soul Player\logs\
